# ValScanner v0.2.5 — Release Notes

**Release date:** 2026-06-01
**Status:** Patch release

---

## Overview

This release focuses on getting files in and out of ValScanner more easily and making the GUI faster and friendlier. You can now drag files from the file list straight into Finder or Explorer, drop a folder onto the scan field to start indexing it, and copy paths or filenames with the standard keyboard shortcuts. The folder tree opens far quicker on large scans thanks to lazy loading, parallel scans are now supported, and a new `--db-status` CLI command shows exactly what your database contains.

---

## User-visible changes

- Drag files from the Details, Grid, or Compact view directly out to Finder, Explorer, or any application that accepts file drops.
- Drag a folder from the Folder tree into Finder or Explorer to reveal it.
- Drop a folder from the OS file browser onto the scan target field to fill in its path.
- Copy selected paths with `Ctrl+C` and copy filenames with `Ctrl+Shift+C` from any file view.
- Click the new copy buttons next to **Path** and **SHA-256** in the Details panel to copy each value to the clipboard.
- Navigate up one folder level with `Backspace` or `Alt+Up`, or by clicking the new `..` row at the top of a folder listing.
- Run multiple scans at once — starting a new scan no longer queues behind the running one, and the most recent folder click wins when navigating.
- New CLI command `valscanner --db-status` prints database size, per-table row counts, a per-scan breakdown of indexed bytes, and any orphan rows.
- New CLI flag `--dump-scan-ids 1,3,5` exports only the listed scans when using `--dump-to-sqlite`.
- New CLI flags `--no-dump-thumbnails` and `--no-dump-samples` skip blob phases during dump/load for faster, smaller transfers.
- New CLI flag `--zip-blobs [FILE]` writes thumbnails and media samples to an accompanying ZIP archive on dump and restores them from one on load — handy for moving blobs alongside a slim SQLite file.
- Folder tree opens much faster on large scans: child branches are now built on demand when you expand them, and folder/file icons are cached.
- Accessible names, descriptions, and tab order added across the GUI — dialogs, scan controls, filter bar, view buttons, console, and Similar Folders panel — improving screen-reader and keyboard navigation.
- A visible focus outline now appears on buttons, inputs, and views when navigating with the keyboard.
- Icons re-render correctly after a theme change.

---

## Upgrade notes

- A new database migration (`0008`) adds btree indexes on `files.path` and `folders.path` to speed up the folder browser's path-prefix queries. On PostgreSQL this runs with `CREATE INDEX CONCURRENTLY` so it won't block writes; on SQLite it's a quick offline `CREATE INDEX`. The migration runs automatically on first launch.
