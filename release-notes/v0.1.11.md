# ValScanner v0.1.11 — Release Notes

**Release date:** 2026-05-25  
**Status:** Patch release

---

## Overview

v0.1.11 fixes the Windows installer build process. The Inno Setup compiler was rejecting the installer configuration due to an invalid directive value, which prevented the Windows executable from being built.

---

## Fixes

- **Windows installer build** — corrected `PrivilegesRequiredOverridesAllowed` directive syntax in Inno Setup configuration to allow both standard-user and admin installation modes.

---

## Upgrading

```bash
pip install --upgrade valscanner
```

Windows users can re-download the latest installer from the [Releases](https://github.com/valabji/val-scanner/releases) page.
