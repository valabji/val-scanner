# ValScanner v0.2.6 — Release Notes

**Release date:** 2026-06-01
**Status:** Patch release

---

## Overview

ValScanner is now in Beta. This release adds a first-launch tour that walks new users through scanning, browsing, finding similar folders, filtering, and stopping background tasks — replayable anytime from the Help menu. Deleting scans now confirms with a clear status message (and a matching one if you undo), and the user-facing wording across the app has been tightened so the same terms are used everywhere.

---

## User-visible changes

- First-launch spotlight tour introduces scanning, the folder tree, the Similar Folders tab, view filters, view modes, the background-task pill, and how to cancel a running task. The tour can be replayed anytime from **Help → Show tour**, and is dismissable with Esc/Skip.
- Deleting scans now emits a status-bar confirmation (“Deleted N scans.”) once the undo window closes, and undoing a pending delete confirms with “Restored N scans.”
- User-facing terminology is now consistent across the app: messages, tooltips, accessibility descriptions, and prompts have been reworded to say "scan" / "scanned" / "database" uniformly (e.g. “Pick a folder to scan…”, “Already-scanned files are kept”, “your scanned files are not affected”).
- Similar-folder analysis now streams pair rows as they're computed instead of buffering the full list first, so very large analyses start producing results sooner and use less peak memory.
- ValScanner is promoted from Alpha to Beta on PyPI, signalling the app is suitable for everyday use.

---

## Internal

- Added automated test coverage for drag-out MIME data (`text/uri-list` + plain text paths) from the file table, icon grid, and folder tree, and for non-empty accessible names on every interactive control across the detail, scans, folders, console, similar-folders, and scan-options panels.
- Added interaction tests for multi-row selection, the delete-with-undo flow (commit, undo, cancelled-by-dialog, no-selection, supersede), Details/Grid/List view-mode switching, and the similar-folders card select/dismiss/sort flow.
- Added web-API integration tests for `/api/similar`, `/api/export/json`, and `/api/files` filter combinations.
- Visual rhythm tokens (`Spacing`, `Margins`, `Sizes`) were added and pixel literals across dialogs, panels, and widgets were swept onto them for consistent spacing.
- PyPI publishing now triggers on tag push (`v*`) rather than on GitHub release publication.
