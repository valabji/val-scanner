# ValScanner v0.1.14 — Release Notes

**Release date:** 2026-05-25  
**Status:** Minor release

---

## Overview

v0.1.14 adds file timeout protection, comprehensive logging with rotating file handlers, and optional console-free output. Scans can now skip files that take too long to process, and all operations are logged with detailed DEBUG-level tracing for troubleshooting.

---

## User-visible changes

- **File timeout protection** — Add `--file-timeout SEC` to skip files exceeding the timeout (default: 120s). Prevents scans from hanging on problematic files; timed-out file counts are reported in the summary.
- **Comprehensive logging** — Add `--log-file PATH` to write detailed logs with automatic file rotation, `--log-level LEVEL` to control verbosity (DEBUG/INFO/WARNING/ERROR), and `--log-max-size BYTES` / `--log-backup-count N` for rotation management.
- **Clean console output** — Add `--log-no-console` to suppress logging to stderr while maintaining file logging; keeps terminal output clean in production and automation scenarios.
- **DEBUG-level tracing** — New detailed DEBUG logging throughout the scanner pipeline: directory traversal, file processing, metadata extraction, tagging, database operations, folder tracking, and timeout events.

---

## Upgrade notes

No breaking changes. All logging parameters are optional; existing scripts continue to work unchanged. The file timeout defaults to 2 minutes; modify `--file-timeout` only if you encounter timeout issues with slow files.

---

pip install --upgrade valscanner
