# ValScanner v0.1.4 — Release Notes

**Release date:** 2026-05-19  
**Status:** Incremental release

---

## Overview

v0.1.4 introduces a full-stack web UI, a new Process Panel for monitoring background workers, folder clustering in the similarity engine, and responsive cancellation throughout. It also ships the first cross-platform CI/CD build pipeline that produces native installers for macOS, Windows, and Linux on every release.

---

## New Features

### Full-stack web UI

A complete browser-based interface is now available alongside the desktop GUI. Run `valscanner-web --db my.db` to serve it on port 7070. Includes pages for Scans, Files, Folders, Similar Folders, and a Detail Panel — with pagination, search, tag chips, size bars, and score badges.

- Development mode (`--dev`) proxies to a Vite dev server on :5173.
- `scripts/build_web.sh` bundles the SPA into the package for production use.

```bash
# Development (two terminals)
valscanner-web --db my.db --dev   # Python API on :7070
cd web-ui && npm run dev           # Vite on :5173

# Production
./scripts/build_web.sh
valscanner-web --db my.db
```

### Process Panel (activity monitor)

A new dockable Process Panel tracks background workers (scan, analysis, DB load) in real time:

- Detects worker freeze and surfaces it visually.
- Shows live progress with percentage and ETA.
- Auto-clear on completion option.
- Starts docked; visibility is saved and restored between sessions.

### Browser view for large databases

A paginated folder-navigation browser mode in the GUI loads database content in the background, preventing the window from freezing when opening very large `.db` files.

### Folder clustering (N-member groups)

The Similar Folders panel now clusters related folders into N-member groups rather than showing only pairwise matches, giving a clearer picture of large sets of duplicated or near-duplicate directories.

### Improved cancellation

Scan and analysis workers now use `threading.Event` for responsive cancellation. The cancel check runs at directory level (not just file level), so large trees cancel quickly. A "Cancelled" status is shown in the Process Panel.

### Real progress percentage and ETA

Both the scan and similarity-analysis workers emit accurate progress percentages and estimated time-to-completion rather than indeterminate spinners.

## UI / UX Improvements

- **Icon overhaul** — emoji icons replaced with `qtawesome` MDI vector icons throughout the GUI (file cards, panels, toolbar, preferences, console).
- Progress animation stops cleanly when a worker finishes or errors.
- Process dock visibility is correctly restored from saved preferences on startup.
- Workers are registered with the ProcessRegistry before being started, preventing a start-up race condition.

---

## Infrastructure / CI

- New **cross-platform GitHub Actions build workflow** (`.github/workflows/build.yml`) produces a signed macOS `.app`, Windows `.exe` (Inno Setup installer), and Linux AppImage on every release; each artifact is attached directly to its GitHub release.
- New **web CI workflow** (`.github/workflows/web.yml`) runs the FastAPI and Vite test suites on every push.
- Inno Setup paths corrected for CI environments; `scripts/bump_version.py` updated accordingly.

## Bug Fixes
