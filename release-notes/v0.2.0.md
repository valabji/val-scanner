# ValScanner v0.2.0 — Release Notes

**Release date:** 2026-05-27
**Status:** Minor release

---

## Overview

This release reworks the **Process Monitor** into a full-featured live system view, lands a round of GUI performance and portability improvements, and adds a **scan-root remap** so renamed or moved scan trees can be repointed without re-scanning. Under the hood, PyPDF2 is replaced by `pypdf`, the cross-platform CI matrix now covers Windows / macOS / Linux, and a large batch of new tests fills in coverage gaps across `core/`, `gui/`, and `web/`.

---

## User-visible changes

- **Process Monitor — major rebuild:** the panel grew from a basic process list into a live system view with richer per-process detail, CPU/memory sparklines, persistent column/sort state, and a redesigned layout (`valscanner/gui/panels/process.py`).
- **Scan root remap:** if a scanned folder was renamed or moved, you can now remap the scan's root path from both the CLI and the **Scans** panel without re-indexing. New CLI flag exposed in `valscanner` and a new action in the GUI's Scans panel.
- **GUI performance pass:** the file table now uses an incremental refresh path (no more O(n²) full rebuild on each update), background scans are throttled to keep the UI responsive, and the thumbnail cache has a hard memory cap so long-running sessions stay bounded.
- **Smoother sparklines:** the sparkline widget used by the Process Monitor was reworked for less flicker and more consistent baseline behavior.
- **Portability fixes (GUI):** window geometry is clamped to the available screen on startup (no more off-screen windows when monitors change), "Open" and "Reveal in file manager" actions use safer per-OS launchers, and remaining `os.path` call sites were migrated to `pathlib`.
- **PDF metadata via `pypdf`:** the optional PDF metadata extractor now uses the maintained `pypdf` package instead of the deprecated `PyPDF2`. Behavior is unchanged for users; the optional extra in `pyproject.toml` was updated accordingly.

---

## Upgrade notes

- **Optional PDF support:** if you previously installed `PyPDF2` manually to enable PDF metadata, install `pypdf` instead (or reinstall the optional extras: `pip install --upgrade "valscanner[rich]"`). `PyPDF2` is no longer imported.
- **Process Monitor layout:** column widths and sort order are now persisted; the first launch after upgrade resets to the new defaults. Subsequent changes are remembered.
- **No database migration is required** for this release.

---

## Fixes

- **PostgreSQL FTS tokenization:** corrected the `tsvector` configuration so multi-token filenames index and match consistently with the SQLite FTS5 path.
- **ThumbnailCache init regression:** restored the initial-state fields on `ThumbnailCache` that had been dropped during the cache cap rework, fixing a startup edge case.
- **GUI shutdown on close (CI SIGABRT):** scan and analysis workers are now drained before the main window exits, eliminating intermittent `SIGABRT` on CI teardown and stray Qt warnings on quit.
- **Web tests teardown:** scan workers are drained before the web test fixture tears down, fixing flaky shutdowns.

---

## Internal

- **Cross-platform CI matrix:** the test workflow now runs on Ubuntu, macOS, and Windows. The macOS-13 (Intel) runners were dropped from the matrix.
- **Windows CI hardening:** test fixtures and subprocess invocations were adjusted for Windows tempfile and environment semantics so the suite is green on Windows runners.
- **Test coverage expansion:** new suites for `core/db`, `core/filters`, `core/logging_config`, `core/metadata`, `core/tagging`, `core/transfer`, `core/repository/{cache,scans,search}`, `core/similarity_units`, `cli`, GUI settings migration / worker contracts, and additional `web/` router gap coverage. Net +1700 lines of tests.
- **Documentation:** `CLAUDE.md` now documents the dual-backend (SQLite + PostgreSQL) story end-to-end, including FTS bootstrap differences and PostgreSQL space-reclaim guidance.

## Upgrading

```bash
pip install --upgrade valscanner
```

If you use the rich output or web UI:

```bash
pip install --upgrade "valscanner[rich]"
pip install --upgrade "valscanner[web]"
```
