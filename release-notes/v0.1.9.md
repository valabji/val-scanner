# ValScanner v0.1.9 — Release Notes

**Release date:** 2026-05-24  
**Status:** Patch release

---

## Overview

v0.1.9 adds a real-time progress bar to the CLI scanner. When running a scan
from the terminal (not in `--verbose` mode and with TTY output), users now see
a live progress indicator showing files scanned, completion percentage, scan rate,
and estimated time remaining. The progress bar automatically clears on completion
for clean terminal output.

---

## User-visible changes

- **CLI progress bar** — live progress indicator during scans showing file count, percentage, rate (files/sec), and ETA; only displays in interactive terminal mode (hidden in `--verbose` or when piped).

---

## Upgrading

```bash
pip install --upgrade valscanner
```
