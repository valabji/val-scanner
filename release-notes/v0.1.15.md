# ValScanner v0.1.15 — Release Notes

**Release date:** 2026-05-25
**Status:** Patch release

---

## Overview

This patch optimizes scan resumption by skipping redundant processing of already-indexed files. When resuming an interrupted scan, ValScanner now checks if each file has already been processed before computing its hash or generating thumbnails, resulting in dramatically faster resume operations.

---

## User-visible changes

- Resume scans now skip already-indexed files, avoiding redundant hash computation and thumbnail generation.

---

## Fixes

- Resume scans no longer re-hash and re-thumbnail files that were already processed in the previous scan session.

---

## Internal

- Added `file_exists()` method to the repository layer for efficient duplicate detection.
- Scanner now pre-checks file existence before processing, eliminating expensive I/O operations for resumed scans.

---

## Upgrading

```bash
pip install --upgrade valscanner
```

If you use the rich output or web UI:

```bash
pip install --upgrade "valscanner[rich]"
pip install --upgrade "valscanner[web]"
```
