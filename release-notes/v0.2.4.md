# ValScanner v0.2.4 — Release Notes

**Release date:** 2026-05-29
**Status:** Patch release

---

## Overview

This patch release makes browsing very large scans noticeably smoother. The recursive "all subfolders" file view now streams files in a page at a time as you scroll, instead of loading the entire scan up front, and that same lazy paging now applies to the grid and list views as well as the table — all while keeping your scroll position steady. Alongside that, database transfers are now resilient to corrupt thumbnail and media-sample tables, and the `rich` extra installs cleanly on Windows with Python 3.8.

---

## User-visible changes

- The recursive "all subfolders" file view now loads files page-by-page as you scroll, so opening a path that spans an entire large scan no longer stalls while everything loads at once; the tab header shows the full file count for that view.
- Lazy paging now works in the grid and list views, not just the table — scrolling toward the bottom of whichever view is active streams in the next page and preserves your scroll position (previously the grid and list jumped back to the top when more files arrived).

---

## Fixes

- Transferring a database with a corrupt thumbnail or media-sample table no longer aborts the whole transfer. ValScanner now salvages the rows it can read, warns about the rest, and always preserves the critical scan, file, and folder data.
- `pip install "valscanner[rich]"` now succeeds on Windows with Python 3.8. The optional AVIF plugin, which has no compatible prebuilt wheel for that combination and previously failed to build from source, is skipped there; AVIF support remains available everywhere else.

---

## Internal

- GitHub release artifacts are now published as prereleases, using the matching `release-notes/vX.Y.Z.md` file as the release body.
- The version-bump script can now auto-draft a release-notes file from the commits since the previous tag (pass `--no-notes` to skip).
- Removed the now-unused initial-load and lazy-load workers, folding pagination into the shared browser loader.

---

## Upgrading

```bash
pip install --upgrade valscanner
```
