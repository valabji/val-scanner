# ValScanner v0.2.7 — Release Notes

**Release date:** 2026-06-06
**Status:** Patch release

---

## Overview

This release is focused on speed and search ergonomics. Scans, similarity analysis, and the GUI hot paths are all noticeably faster on large libraries, and full-text search is now its own standalone command with category and per-scan filters. The onboarding overlay also no longer crashes on window resize and correctly passes clicks through to the highlighted control.

---

## User-visible changes

- New standalone `--search TERM` command — query the database without re-scanning, with `--scan-id`, `--category CAT`, and `--limit N` filters. Replaces the old `--query` flag, which has been retired.
- Search results now show which scan each hit came from alongside the path, category, size, and tags.
- `--open-settings` accepts an optional editor argument (e.g. `--open-settings code`, `--open-settings nano`) to launch a specific editor instead of the system default.
- Similarity analysis runs in parallel by default. New `--analysis-workers N` flag (0 = auto / CPU count, 1 = sequential) and the analysis banner now prints the worker count in use.
- Similarity analysis is dramatically faster on large libraries: candidate pairs are pruned by shared name / hash / extension before scoring, with memory-safe fallbacks for very low thresholds and oversized datasets.
- Scans are significantly faster — bulk file inserts, batched per-scan path lookups for resume, hoisted glob compilation, faster SHA-256 reads, larger SQLite page cache and memory-mapped reads, and cached timestamp formatting all reduce per-file overhead.
- GUI file list and grid scroll more smoothly: delegates and the table model now cache colors, brushes, and fonts instead of rebuilding them on every paint.
- Skip filters (`--skip-hidden-dirs`, `--skip-vcs`, `--skip-binaries`, `--skip-temp`, `--skip-logs`, …) now apply to `--dump-to-sqlite` and `--load-from-sqlite` as well as scans, with filtered counts shown in the progress output.
- New `--log-skipped` flag prints the path of every file or folder dropped by skip filters during dump/load, routed through the standard logger so it follows `--log-file` / `--log-no-console`.
- Frozen Windows / macOS builds correctly support multiprocessing — `freeze_support()` is now called on app startup so similarity workers no longer fail to spawn in installed builds.

---

## Fixes

- Onboarding overlay no longer crashes when the main window is resized, and clicks on the highlighted target now pass through the spotlight cutout instead of being swallowed by the overlay.

---

## Internal

- CLI search exposed as `search_db()` in `valscanner.core.db` (was `query_db`); tests and references updated.
- FTS availability is probed once per engine and cached, eliminating a redundant connection on every search.
- File export streams rows in batches instead of materializing the entire table in memory.
- Tag generation hoists keyword dictionaries and size thresholds to module scope and matches name keywords in a single regex pass.
