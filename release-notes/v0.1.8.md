# ValScanner v0.1.8 — Release Notes

**Release date:** 2026-05-23  
**Status:** Patch release

---

## Overview

v0.1.8 greatly expands the CLI surface. The scanner now accepts fine-grained
skip filters, thumbnail and media-sample controls, a standalone similarity
analysis command, and database portability via `--dump-to-sqlite` /
`--load-from-sqlite`. A new `--open-settings` shortcut opens the settings file
directly in the system editor. No GUI changes in this release.

---

## User-visible changes

- **`--analyze`** — run folder similarity analysis after a scan, or standalone
  against an existing database; results are printed in a scored table with
  child pairs indented below parent pairs.
- **Analysis tuning flags** — `--min-files N` (default 3), `--threshold F`
  (default 0.40), `--analysis-results N` (default 200), and
  `--analysis-scan-id ID` to scope analysis to one scan.
- **`--dump-to-sqlite FILE`** — export the active database to a portable SQLite
  file; combine with `--include-analysis` or `--include-cache` to also copy
  those tables.
- **`--load-from-sqlite FILE`** — import scans from a SQLite file into the
  active database; same `--include-*` options apply.
- **`--open-settings`** — open `settings.json` in the system default editor
  and exit.
- **Thumbnail controls** — `--no-thumbnails` to skip generation,
  `--thumb-size PX` (default 128), `--thumb-quality PCT` (default 75).
- **Media sample controls** — `--no-samples` to skip generation,
  `--sample-duration SEC` (default 5).
- **Scan skip filters** — eight new flags to exclude files and directories
  during a scan: `--skip-hidden-dirs`, `--skip-vcs`, `--skip-system`,
  `--skip-caches`, `--skip-hidden-files`, `--skip-binaries`, `--skip-temp`,
  `--skip-logs`.

## Internal

- New `valscanner/core/transfer.py` module handles database-to-database copy
  for the dump/load commands.
