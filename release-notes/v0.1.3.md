# ValScanner v0.1.3 — Release Notes

**Release date:** 2026-05-17  
**Status:** First public release

---

## Overview

ValScanner is a cross-platform file scanner that builds a searchable SQLite database of everything inside a directory tree. It ships as both a command-line tool and a PySide6 desktop GUI, and can extract rich metadata, generate thumbnails, detect similar folders, and export results to CSV or JSON.

---

## Features

### Core scanner

- Recursively walks any directory tree and writes one row per file into a local SQLite database.
- Automatically categorises files by extension and MIME type (documents, images, audio, video, code, archives, fonts, …).
- Computes **SHA-256 hashes** for exact duplicate detection (opt-out with `--no-hash`).
- Skips hidden directories, VCS directories (`.git`, `.svn`, …), build/cache directories (`node_modules`, `__pycache__`, `venv`, …), and OS system directories by default.
- Accumulates **folder-level** byte and file-count totals up the full ancestor chain, stored in a dedicated `folders` table.
- Stores all data in a portable `.db` file — multiple independent scans can share the same database.

### Rich metadata extraction (optional libraries)

| Library   | What is extracted |
|-----------|------------------|
| **Pillow** | Image dimensions, EXIF tags (camera model, GPS, focal length, …), auto-generated JPEG thumbnails |
| **mutagen** | Audio bitrate, sample rate, duration, title, artist, album, genre |
| **PyPDF2** | PDF page count, title, author, subject |

All three libraries are optional. ValScanner runs without them; it simply skips the metadata it cannot read.

### Rule-based file tagging

Every file receives a set of auto-generated tags derived from:
- Extension and MIME category (e.g. `image`, `audio`, `pdf`)
- Filename keywords and path components
- File size buckets (`tiny-file`, `small-file`, `large-file`, `huge-file`)
- Special markers: `hidden-file`, `dotfile`, `binary`, `temp-file`, `log-file`

Tags are stored as a space-separated string and indexed via FTS5 for fast full-text search.

### Folder similarity analysis

Identifies pairs of folders that appear to hold the same or very similar content using a weighted multi-factor score:

- **Filename Jaccard** — overlap of stem names between the two folders
- **Extension cosine** — similarity of file-type distributions
- **Size ratio** — how close the total bytes are
- **SHA-256 Jaccard** — exact-file overlap when hashes are present

Results are returned as a hierarchy: parent/ancestor folder pairs contain their nested child pairs. The GUI presents these as collapsible cards in the **Similar Folders** panel.

### Export

- `--export-csv` — flat CSV of every indexed file
- `--export-json` — JSON array of every indexed file with full metadata

### Full-text search (FTS5)

The database maintains an FTS5 virtual table (`files_fts`) mirroring the `files` table. Inserts and deletes are kept in sync via SQLite triggers, enabling fast keyword search over filenames, paths, MIME types, and tags without a separate indexing step.

## Interfaces

### CLI (`valscanner`)

```
valscanner /path/to/scan
valscanner /path/to/scan --db my.db --label "Work laptop" --no-hash --export-csv --export-json --verbose
valscanner --list-scans --db my.db
valscanner --delete-scan 3 --db my.db
```

### GUI (`valscanner-gui`)

A PySide6 desktop application with:

- **Scan panel** — configure root directory, database path, hashing, and metadata options via a dialog.
- **Files panel** — searchable, sortable table (or card grid) of every indexed file; numeric sort for size column.
- **Folders panel** — tree view of folder byte/file totals; sortable by size.
- **Similar Folders panel** — collapsible pair cards showing similarity scores and relative paths; background analysis thread keeps the UI responsive.
- **Scans panel** — manage multiple scan sessions stored in a single database.
- **Detail panel** — right-side inspector showing full metadata, thumbnail, and tag chips for the selected file.
- **Console panel** — live stderr feed and scan progress.

Dark-themed throughout; colours are assigned per file category.

## Database schema

| Table | Purpose |
|-------|---------|
| `scans` | One row per scan session (label, root, file count, total size, timestamp) |
| `files` | One row per file; `extra_meta` JSON blob holds rich metadata |
| `folders` | Cumulative byte/file counts for every ancestor directory |
| `thumbnails` | JPEG blobs keyed by `file_id` |
| `media_samples` | Low-quality audio/video clips keyed by `file_id` |
| `files_fts` | FTS5 virtual table; auto-synced via triggers |

## Installation

```bash
# Minimum (GUI included)
pip install valscanner

# With rich metadata support
pip install "valscanner[rich]"

# From source (editable)
git clone https://github.com/valabji/myscanner
pip install -e ".[rich]"
```

**System requirements:** Python ≥ 3.8, PySide6.

Pre-built installers for macOS and Windows are available on the [Releases](../../releases) page and are produced by the included CI/CD workflow (PyInstaller + Inno Setup on Windows).

## Known limitations

- Media sample extraction (audio/video clips) requires `ffmpeg` in `PATH` and is not yet exposed in the GUI.
- The similarity threshold (default 0.40) and minimum file count per folder (default 3) are not yet configurable from the GUI — use the Python API directly.
- PDF metadata extraction uses PyPDF2, which may fail on encrypted or malformed PDFs; errors are silently swallowed.
- FTS5 search in the GUI searches filenames and tags only; a dedicated search bar with full query syntax is planned.
