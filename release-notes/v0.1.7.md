# ValScanner v0.1.7 — Release Notes

**Release date:** 2026-05-23  
**Status:** Minor release

---

## Overview

v0.1.7 is a full GUI overhaul delivered in 13 sequential redesign phases.
The desktop app ships with a new Catppuccin-based palette, bundled Inter and
JetBrains Mono fonts, collapsible rail sidebars, a Volume Map in the Folders
panel, a hover-peek floating card on file rows, an inline Process Monitor
column, a reworked filter bar, and a redesigned grid delegate. On top of the
visual work, crash-resume lands: interrupted scans are detected on next launch
and can be continued from where they stopped. Numerous layout and interaction
regressions are also fixed in this release.

---

## User-visible changes

- **Catppuccin theme (default)** — the warm charcoal + amber palette introduced
  in Phase 1 is now the shipped default; Catppuccin Mocha replaces the previous
  dark theme.
- **Bundled fonts** — Inter (UI text) and JetBrains Mono (code / paths) are
  embedded in the package; no system font required.
- **Row density presets** — three density options (S / M / L, 26 / 32 / 38 px)
  are available in the file table toolbar.
- **Inline scan progress** — an amber pill and progress readout appear directly
  in the filter bar while a scan runs; no separate dialog needed.
- **SHA-256 hash column** — the file table has a new Hash column; the Inspector
  (formerly Detail Panel) shows the full SHA-256 digest.
- **Inspector panel renamed** — "Detail Panel" is now "Inspector" throughout the
  UI.
- **EXIF section in Inspector** — image EXIF metadata (camera model, focal
  length, GPS, etc.) surfaces in a dedicated collapsible section.
- **Collapsible rail sidebars** — the Folders and Inspector panels can be
  collapsed to a narrow rail icon strip with a single click, reclaiming
  horizontal space.
- **Process Monitor column** — a fourth splitter column shows live CPU / memory
  usage for the running scan process.
- **Volume Map in Folders panel** — a treemap-style widget visualises relative
  disk consumption for the selected folder's children; resizable, scrollable,
  and collapsible.
- **Hover-peek floating card** — hovering over a file row shows a compact
  floating card with thumbnail preview, metadata, and tags without navigating
  away.
- **Redesigned grid delegate** — the grid-view file card uses a muted fill with
  a centred icon, consistent folder icon treatment, and sharper typography.
- **Crash-resume** — if ValScanner exits while a scan is in progress, the next
  launch detects the interrupted scan and offers to resume from the last
  committed position.
- **Collapse toggle on Similar Folders cards** — each folder-pair card can be
  collapsed independently; state is preserved while the panel is open.
- **Single-click / double-click on scan rows** — single click selects the scan
  row; double-click loads it into the active view (previously a single click
  loaded it immediately).

## Fixes

- Filter pill now uses 3-state behaviour: off → active (show matching) → inverse
  (hide matching); tooltips explain each state.
- Filter bar hides when the pill is clicked, shows file count only when the bar
  is hidden.
- Filter bar layout: two-row layout, pill enabled by default, depth buttons
  disabled until a folder is selected.
- Volume Map is now resizable and collapsible inline.
- "No parts" label uses `show()`/`hide()` instead of `insertWidget()` to avoid
  layout thrash.
- Database chip text updates correctly when a new database loads.
- Grid card icons: muted fill, centred `QIcon.paint()`, folder icon support.
- Header label background no longer bleeds outside the label bounds; tooltip
  events no longer propagate past the header.
- Collapsed rail height now fills the full column height.
- Window size is locked: layout collapse/expand no longer resizes the main
  window.
- Subfolder toggle unified: browse toggle removed, browser mode used throughout.
- Segfault on Wayland: `HoverPeekCard` now uses `Qt.Tool` instead of
  `Qt.ToolTip`.
- `blockSignals()` was called on a signal instead of the `QObject`; fixed.
- `list_scans` fallback handles unmigrated databases; `actually_resumed`
  tracking corrected.
- Clone URL, repo root label, and `pyproject.toml` description and URLs
  corrected.
