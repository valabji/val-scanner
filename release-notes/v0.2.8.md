# ValScanner v0.2.8 — Release Notes

**Release date:** 2026-06-06
**Status:** Patch release

---

## Overview

This patch release fixes two papercuts that mainly affected Windows users and anyone navigating large scans with the keyboard. Exclude patterns now match consistently regardless of the host operating system's path separator, and pressing Enter on a folder in the file list drills into it instead of trying to open it as a file.

---

## User-visible changes

- Pressing Enter on a folder row in the file list now drills into that folder, matching the behavior of double-click and clicking the navigation breadcrumbs.
- Exclude patterns are now matched against forward-slash paths on Windows, so the same patterns work identically across Windows, macOS, and Linux.

---

## Fixes

- Fixed exclude patterns silently failing to match on Windows when paths contained backslash separators.
- Fixed Enter key on a folder row attempting to "open" the folder as a file rather than navigating into it.
