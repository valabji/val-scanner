# ValScanner v0.1.6 — Release Notes

**Release date:** 2026-05-22  
**Status:** Patch release

---

## Overview

v0.1.6 is a GUI responsiveness and polish release. The desktop app now
remembers your window layout, filter state, and last-used database across
restarts. A new scan queue lets you kick off a second scan while one is still
running. Analysis results are cached in the database so re-opening a DB is
instant. Two regressions from v0.1.5 are also fixed: the Folders panel no
longer freezes the UI on large databases, and thumbnails now display reliably
in the Detail panel.

---

## User-visible changes

- **Window state persistence** — window geometry, splitter positions, file-table
  column widths and sort order, view mode (Details / Grid / List), and the
  expanded/collapsed state of the Scan Options filters group are all saved to
  `QSettings` and restored on next launch.
- **Filter persistence** — file-table view filters and Similar Folders panel
  controls (sort, threshold, min-files, min-size, selected scan IDs) survive
  app restarts.
- **Recent databases** — the last 10 opened `.db` files are remembered; both
  the File menu and the welcome screen show a quick-open chip strip.
- **System theme support** — a new "System" theme option follows the OS
  light/dark preference automatically. The theme selector now shows Dark,
  Light, System, and High Contrast.
- **Scan queue** — if a scan is already in progress when you start another,
  the new path is queued and starts automatically when the first scan
  finishes. No requests are silently dropped.
- **Instant analysis on DB open** — `AnalysisWorker` results are cached in a
  new `gui_cache` table (`migration 0006`). Re-opening a database that was
  already analysed skips the heavy computation and loads from the cache.
  `ScanWorker` warms the cache eagerly before emitting `done`, so the Similar
  Folders panel is populated without a second wait.
- **Undo toast for destructive actions** — scan deletion now shows a brief
  banner with an Undo button before the row is removed from the database.
  Standardised error modals and confirmation dialogs are used consistently
  across all panels.
- **Folders panel no longer freezes** — folder data is now loaded in a
  background `FolderLoadWorker` thread instead of on the main thread, keeping
  the UI responsive when opening large databases.
- **Thumbnail display fix** — thumbnail bytes are correctly cast before being
  passed to `QPixmap.loadFromData`, and a guard prevents a crash when the
  blob is absent or corrupt.

---

## Upgrade notes

- Migration `0006_add_gui_cache` runs automatically on first connect and adds
  the `gui_cache` table. No manual steps needed.
- `QSettings` keys are now versioned (`app/schema_version = 1`). On first
  launch after upgrade, old flat keys (`windowGeometry`, `splitterState`, …)
  are migrated into the new `window/*` namespace automatically.

---

## Internal

- New GUI test suite under `tests/gui/`: smoke, panel, flow-layout,
  settings-migration, workers-contract, and feedback tests.
- `valscanner/gui/feedback.py` — centralised `Level` taxonomy, `UndoToast`,
  `notify_error`, and `confirm_destructive` helpers used across all panels.
- `valscanner/gui/persistence.py` — `Keys` registry, `settings()`, `get_json`
  / `set_json` helpers, and the `0 → 1` QSettings schema migration.
- `valscanner/gui/recent.py` — `RecentDBsModel` singleton; both File menu and
  welcome screen subscribe to its `changed` signal.
- `valscanner/gui/layouts.py` — `FlowLayout` extracted from `detail.py` into
  its own module.
- `pyproject.toml` — `pytest-qt` added as a dev dependency.
