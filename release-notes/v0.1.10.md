# ValScanner v0.1.10 — Release Notes

**Release date:** 2026-05-24  
**Status:** Patch release

---

## Overview

v0.1.10 fixes a critical Windows launch crash and improves the installer to let users choose between per-user or system-wide installation. The crash was caused by PySide6 needing standard library modules that were being excluded from the PyInstaller bundle on Windows.

---

## User-visible changes

- **Windows exe now launches without crashing** — fixed Qt platform plugin initialization error on Windows caused by excluded stdlib modules.
- **Installer privilege prompt** — Windows installer now asks users to choose between current-user or system-wide (admin) installation, making it easier to install for all users on shared machines.

---

## Fixes

- Removed aggressive stdlib exclusions from PyInstaller bundle that broke Windows exe launch.

---

## Upgrading

```bash
pip install --upgrade valscanner
```

Windows users can re-download the latest installer from the [Releases](https://github.com/valabji/valscanner/releases) page.
