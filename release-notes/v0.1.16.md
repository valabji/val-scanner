# ValScanner v0.1.16 — Release Notes

**Release date:** 2026-05-25
**Status:** Patch release

---

## Overview

This patch adds significant performance and flexibility improvements to the CLI. Users can now parallelize scans across multiple worker threads, exclude files matching glob patterns, and skip the pre-scan count phase for faster startup. The progress bar now coexists properly with verbose output, and folder total calculations benefit from ancestor-chain caching.

---

## User-visible changes

- **Parallel workers:** `--workers N` flag (default: 4) enables multi-threaded file processing for faster scans on multi-core systems.
- **Exclude patterns:** `--exclude GLOB` flag (repeatable) skips files whose relative path matches the glob pattern (e.g. `--exclude '*.pyc' --exclude '__pycache__/*'`).
- **Faster startup:** `--no-precount` flag skips the pre-scan file count; progress shows a spinner with a running tally instead of a percentage bar.
- **Progress bar improvements:** Verbose output and progress bar now coexist on TTY without visual garbling; progress clears its line before each verbose print.

---

## Internal

- **Ancestor chain caching:** Folder total calculations now cache the ancestor path chain, eliminating redundant path construction during large scans.
- **Performance test suite:** New `test_scanner_perf.py` validates exclude patterns, worker count consistency, and ancestor caching correctness.

---

## Upgrading

```bash
pip install --upgrade valscanner
```

If you use the rich output or web UI:

```bash
pip install --upgrade "valscanner[rich]"
pip install --upgrade "valscanner[web]"
```
