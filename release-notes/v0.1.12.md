# ValScanner v0.1.12 — Release Notes

**Release date:** 2026-05-25  
**Status:** Patch release

---

## Overview

v0.1.12 fixes the GitHub repository link in the app and Inno Setup installer configuration.

---

## Fixes

- **GitHub repo link** — corrected repository URL in project metadata.
- **Windows installer configuration** — fixed `PrivilegesRequiredOverridesAllowed` directive syntax in Inno Setup to allow both standard-user and admin installation modes.

---

## Upgrading

```bash
pip install --upgrade valscanner
```

Windows users can re-download the latest installer from the [Releases](https://github.com/valabji/val-scanner/releases) page.
